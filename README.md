# Finance Pessoal

Sistema de controle financeiro pessoal moderno e eficiente.

## 📂 Estrutura do Repositório

- `/web`: Frontend desenvolvido em Next.js 16 com integração Supabase.
- `/web/supabase/migrations`: Scripts SQL para setup do banco de dados.
- `.agent`: Configurações e workflows para automação AI.

## 🚀 Como começar

Para instruções detalhadas de como rodar o projeto, acesse o [README do diretório web](./web/README.md).

## 🛠️ Requisitos Rápidos

- **Node.js**: 24.x ou superior.
- **Supabase**: Projeto configurado com Auth, Database e Storage.
